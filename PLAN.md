# PLAN: Polished HTML5 Othello/Reversi for GitHub Pages

## Goal

Build a polished, dependency-free HTML5 Othello/Reversi game suitable for GitHub Pages.

The game will support:

- Standard 8x8 Othello/Reversi rules
- Human player as Black
- Simple AI player as White
- Legal-move hints
- Live score display
- Current turn display
- Restart control
- Dark, modern UI
- Multi-file ES module architecture
- No CDN or external runtime dependencies
- Verification script outline for static checks, pure rules checks, and local HTTP startup
